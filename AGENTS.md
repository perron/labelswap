# AGENTS.md

- Package: `labelswap/` (stdlib only). `model.py` holds the classifier, `tune`, and `shadow`. `cli.py` holds the command line.
- Tests: `python -m unittest discover -s tests`. Every change needs a test.
- Do not add dependencies. Do not commit real user logs; the demo data is generated by `examples/make_tickets.py`.
- To use it in an agent pipeline: call `labelswap decide MODEL --text "..."`, and call the LLM only when `action` is `defer`.
